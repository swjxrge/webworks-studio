## Recommended QA Order

```text
Freeze Scope
→ Review Definition of Done
→ Functional Test
→ Responsive Test
→ Cross-Browser Test
→ Accessibility Test
→ Content / Link Review
→ Log Defects
→ Fix by Severity
→ Retest
→ Regression Check
→ Release Decision
```

---

## Important Rules

1. Test the published GitHub Pages site, not only local files.
2. Record defects before fixing them.
3. Fix Critical defects first.
4. Retest every corrected Critical, High, and Medium defect.
5. Do not add new features during QA.
6. Do not claim a test was performed unless you actually performed it.
7. Automated accessibility tools supplement manual testing; they do not replace keyboard and human review.

Refer to the Week 15 Canvas assignment for full requirements.
